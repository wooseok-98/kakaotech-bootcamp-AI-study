# 🎈 데이터 조회·결합 (필터링 · 그룹화 · 병합)

원하는 행을 골라내고(필터링), 기준별로 묶어 집계하고(그룹화), 여러 표를 합치는(병합) 작업은 데이터분석의 핵심이다.

___

## 📌 필터링 (Filtering)

조건을 적용해 특정 행을 선택한다. 기본은 **불리언 인덱싱**이다.

```python
df[df['나이'] > 30]                         # 단일 조건

# 다중 조건 — & (AND), | (OR), ~ (NOT)
df[(df['나이'] >= 30) & (df['점수'] > 80)]
df[(df['도시'] == '서울') | (df['점수'] >= 90)]
```

> 다중 조건에서는 **각 조건을 괄호로 감싸고 `&` `|` `~`를 써야 한다**. 파이썬 기본 `and` `or` `not`은 Series에 쓸 수 없고, 괄호를 빼면 연산자 우선순위 때문에 에러가 난다.

자주 쓰는 다른 필터링 방법도 있다.

```python
df.query("나이 >= 30 and 도시 == '부산'")   # SQL 스타일 문자열
df[df['도시'].isin(['서울', '부산'])]         # 값 목록 포함 여부
df[df['이름'].str.contains('김')]             # 문자열 패턴 포함
df[df['점수'].notnull()]                      # 결측치 아닌 행

# 조건 결과를 새 열로
df['합격여부'] = df['점수'].apply(lambda x: '합격' if x >= 90 else '불합격')
```

___

## 📌 그룹화 (Grouping)

데이터를 기준별로 묶어 집계한다. **분할(Split) → 적용(Apply) → 결합(Combine)** 패턴으로 동작한다.

```python
df.groupby('부서')['급여'].mean()    # 부서별 급여 평균
df.groupby(['부서', '직급'])['급여'].sum()   # 여러 기준

# agg — 여러 집계 함수 동시 적용
df.groupby('부서')['급여'].agg(['sum', 'mean', 'max'])
```

`agg`와 `transform`의 차이를 아는 것이 중요하다.

```python
# transform — 그룹별 계산 결과를 원래 각 행에 매핑 (행 개수 유지)
df['부서평균'] = df.groupby('부서')['급여'].transform('mean')
```

> **`agg`(또는 일반 집계)는 그룹당 1행으로 축소**되지만, **`transform`은 원본과 같은 행 개수를 유지**하며 각 행에 그룹 결과를 채운다. "전체 대비 그룹 평균" 같은 파생 열을 만들 때 `transform`을 쓴다.

## 📌 병합 (Merging)

여러 DataFrame을 공통 키로 결합한다. **SQL의 JOIN과 동일한 개념**이다.

```python
pd.merge(left, right, on='고객ID', how='inner')
```

`how`로 결합 방식을 정한다.

| 유형 | 설명 |
| --- | --- |
| **inner** | 공통 키가 있는 행만 (기본값) |
| **outer** | 모든 행 포함, 불일치는 NaN |
| **left** | 왼쪽 DataFrame 전체 유지 |
| **right** | 오른쪽 DataFrame 전체 유지 |

![inner/outer/left/right join 비교](여기에-이미지-드래그)

> `how`를 지정하지 않으면 **기본이 `inner`**라 양쪽에 다 있는 키만 남는다. 한쪽 데이터를 모두 보존하려면 `left`/`right`, 전부 남기려면 `outer`를 쓴다.

열 이름 충돌과 단순 연결도 알아둔다.

```python
pd.merge(df1, df2, on='고객ID', suffixes=('_기존', '_신규'))  # 같은 열 이름 구분
pd.concat([df1, df2], ignore_index=True)                     # 키 없이 위아래로 이어붙임
```

> **`merge`는 키를 맞춰 병합**(JOIN)하고, **`concat`은 키 없이 단순히 이어 붙인다**. 같은 구조의 데이터를 쌓을 때는 `concat`, 다른 표를 키로 연결할 때는 `merge`다.
