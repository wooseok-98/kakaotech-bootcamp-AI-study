# 🎈 NumPy

**NumPy**는 대규모 다차원 배열과 행렬 연산을 위한 파이썬 라이브러리다. 파이썬 기본 리스트보다 빠르고 메모리 효율적으로 수치 데이터를 처리한다.

빠른 이유는 두 가지다. 배열의 **모든 요소가 같은 타입으로 연속된 메모리에 저장**되고, 연산이 **C로 구현된 벡터화 연산**이라 반복문 없이 배열 전체에 한 번에 적용되기 때문이다.

```python
import numpy as np
a = np.array([1, 2, 3, 4, 5])
```

___

## 📌 차원과 Shape

- **차원(ndim)**: 배열을 구성하는 축(axis)의 개수. 대괄호 중첩 수준으로 결정
- **shape**: 각 차원별 요소 개수를 나타내는 튜플

| 차원 | 명칭 | 예시 |
| --- | --- | --- |
| 0차원 | 스칼라 | `np.array(42)` |
| 1차원 | 벡터 | `np.array([1, 2, 3])` |
| 2차원 | 행렬 | `np.array([[1, 2], [3, 4]])` |
| 3차원 | 텐서 | `np.array([[[1,2],[3,4]], [[5,6],[7,8]]])` |

```python
array = np.array([[1, 2, 3], [4, 5, 6]])
print(array.ndim)   # 2  → 몇 차원인지
print(array.shape)  # (2, 3) → 2행 3열
```

## 📌 형태 변경

```python
arr = np.array([1, 2, 3, 4, 5, 6])
arr.reshape(2, 3)        # 원소 수 유지하며 형태 변경 (2행 3열)

matrix = np.array([[1, 2, 3], [4, 5, 6]])
matrix.flatten()         # 다차원 → 1차원 (복사본 반환)
matrix.ravel()           # 다차원 → 1차원 (원본 참조 반환)
matrix.transpose()       # 행/열 교환 (전치)
```

> `flatten`과 `ravel`은 결과는 같지만 **동작이 다르다**. `flatten`은 새 **복사본**을 만들고, `ravel`은 원본을 참조하는 **뷰(view)**를 반환한다. 즉 `ravel` 결과를 수정하면 원본도 바뀐다.

## 📌 데이터 타입 (dtype)

NumPy 배열은 **모든 요소가 동일한 타입**을 가져야 한다 (파이썬 리스트와의 차이점). 타입에 따라 요소당 메모리 크기가 정해진다.

```python
arr = np.array([10, 20, 30])
print(arr.dtype)     # int64

arr16 = np.array([10, 20, 30], dtype=np.int16)
print(arr16.itemsize)  # 2  → 요소당 바이트
print(arr16.nbytes)    # 6  → 전체 바이트 (3 × 2)

float_arr = arr.astype(np.float64)   # 타입 변환
```

> `int8`은 `-128~127`, `uint8`은 `0~255`처럼 타입마다 표현 범위가 정해져 있다. 범위가 작은 타입으로 변환하면 **오버플로우**가 날 수 있어 주의한다.

## 📌 인덱싱

배열의 특정 요소에 접근·수정하는 방법으로, 네 가지가 있다.

```python
arr = np.array([10, 20, 30, 40, 50])

# 1) 정수 인덱싱 — 0부터, 음수는 끝에서
arr[0], arr[-1]                 # 10, 50
matrix[1, 2]                    # 2차원은 [행, 열]

# 2) 슬라이싱 — start:end:step (end 미포함)
arr[1:4]                        # [20 30 40]
matrix[:, 1]                    # 모든 행의 2열

# 3) 불리언 인덱싱 — 조건이 True인 요소만 (필터링 핵심)
arr[arr > 20]                   # [30 40 50]
arr[(arr > 10) & (arr < 50)]    # & AND, | OR

# 4) 팬시 인덱싱 — 인덱스 리스트로 여러 개 선택
arr[[0, 2, 4]]                  # [10 30 50]
```

> **슬라이싱은 원본을 공유하는 뷰**지만, **불리언·팬시 인덱싱은 복사본**을 반환한다. 슬라이싱 결과를 수정하면 원본이 바뀌므로 이 차이를 기억해야 한다.

값 수정과 인덱스 위치 찾기도 자주 쓴다.

```python
arr[arr < 50] = 0               # 조건으로 일괄 수정
np.where(arr > 10)              # 조건 만족 요소의 인덱스 반환
```

## 📌 연산과 유니버설 함수 (UFuncs)

**유니버설 함수**는 배열의 각 요소에 반복 적용되는 벡터화 연산이다. 반복문 없이 **같은 위치의 요소끼리(element-wise)** 계산한다.

```python
a = np.array([1, 2, 3]); b = np.array([4, 5, 6])
a + b            # [5 7 9]   (np.add(a, b)와 동일)
a * b            # [4 10 18]
a > 2            # [False False True]  (비교도 요소별)
```

통계 연산에서는 **axis**가 핵심이다.

```python
matrix = np.array([[3, 7, 2], [8, 4, 6]])
np.max(matrix, axis=0)   # [8 7 6] — 열 기준 (행을 따라 아래로 집계)
np.max(matrix, axis=1)   # [7 8]   — 행 기준 (열을 따라 옆으로 집계)
```

> `axis=0`은 "행을 가로질러 아래 방향"으로 집계해 **열별 결과**를, `axis=1`은 "열을 가로질러 옆 방향"으로 집계해 **행별 결과**를 낸다. 데이터분석에서 가장 헷갈리는 부분이다.

## 📌 브로드캐스팅

크기가 다른 배열 간 연산 시, 작은 배열을 자동으로 확장해 맞춘다.

```python
matrix = np.array([[1, 2, 3], [4, 5, 6]])   # (2, 3)
vector = np.array([1, 2, 3])                # (3,)

matrix + vector    # vector가 각 행에 더해짐 → [[2 4 6], [5 7 9]]
matrix + 10        # 스칼라도 전체에 확장
```

> **규칙**: 마지막 축부터 크기를 비교해, **크기가 같거나 한쪽이 1이면** 연산이 가능하다. 이 조건을 못 맞추면 에러가 난다.
