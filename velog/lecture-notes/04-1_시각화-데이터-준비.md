# 🎈 시각화 데이터 준비

**데이터 시각화**는 데이터를 그래프·차트로 표현해 패턴, 추세, 인사이트를 전달하는 과정이다. 시각화를 하려면 먼저 데이터를 **분석 가능한 형태로 준비**해야 한다.

시각화가 필요한 이유는 명확하다. 이상치·계절성 같은 **패턴을 눈으로 파악**하고, 그룹 간 비교를 쉽게 하며, 박스플롯 등으로 데이터 품질 문제를 조기에 발견할 수 있다.

___

## 📌 데이터의 종류

데이터는 구조에 따라 세 가지로 나뉜다. 어떤 종류인지에 따라 준비 방식이 달라진다.

| 종류 | 설명 | 예시 |
| --- | --- | --- |
| **정형 (Structured)** | 행·열의 표 구조, 스키마 기반 | CSV, 엑셀, RDBMS |
| **반정형 (Semi-structured)** | 스키마는 없지만 규칙을 따름 | JSON, XML, YAML |
| **비정형 (Unstructured)** | 고정 구조 없음 | 텍스트, 이미지, 영상, 오디오 |

> 비정형 데이터는 정형 데이터만으로 못 잡는 패턴·의미를 담지만, 분석이 복잡해 **NLP·컴퓨터 비전 같은 별도 기술**이 필요하다. 그래서 보통 분석 전에 정형 형태로 변환한다.

___

## 📌 정형 데이터 처리 흐름

Pandas로 데이터를 다루는 표준 흐름은 다음과 같다.

```
불러오기 → 탐색 → 필터링·변환 → 정리·가공 → 정렬·그룹화 → 저장
```

```python
df = pd.read_csv('data.csv')          # 불러오기
df.info(); df.describe()              # 탐색 (EDA)

df['연봉_원'] = df['연봉'] * 10000     # 변환
df.fillna('없음', inplace=True)        # 결측치 정리
df.drop_duplicates(inplace=True)       # 중복 제거
df['가입일'] = pd.to_datetime(df['가입일'])  # 타입 변환

df.to_csv('processed.csv', index=False)  # 저장
```

## 📌 비정형 데이터 정형화

텍스트나 이미지도 **수치·표 형태로 변환**하면 분석·시각화가 가능하다.

```
수집 → 전처리 → 변환(정형화) → 분석 → 저장
```

텍스트는 길이·단어 빈도 같은 수치로 바꾼다.

```python
df['제목_길이'] = df['title'].apply(len)          # 길이 → 수치
clean = re.sub(r"[^a-zA-Z0-9\s]", "", text)       # 정제
Counter(clean.split()).most_common(10)            # 단어 빈도
```

이미지는 **NumPy 배열**로 변환된다.

```python
image = Image.open("example.jpg").resize((256, 256))
arr = np.array(image)     # (256, 256, 3) = (높이, 너비, RGB 채널)
arr[:, :, 0].mean()       # Red 채널 평균
```

> 이미지는 <span style="color:red">(높이, 너비, 채널)</span> 형태의 3차원 배열이다. 컬러는 RGB 3채널, 흑백은 1채널이다. 딥러닝 모델의 이미지 입력이 이 구조를 그대로 사용한다.
