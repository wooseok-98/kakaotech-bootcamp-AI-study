# 🎈 데이터 정제·변형 (결측치 · 피벗 · 문자열)

수집한 데이터는 대부분 그대로 쓸 수 없다. 빠진 값을 채우고, 중복을 없애고, 표 구조를 바꾸고, 문자열을 정리하는 정제 과정이 필요하다.

___

## 📌 결측치 처리

Pandas에서 결측치는 `NaN` 또는 `None`으로 표시된다. **탐지 → 제거 또는 대체** 순서로 처리한다.

```python
df.isnull().sum()        # 열별 결측치 개수 (탐지)

# 제거
df.dropna()              # 결측치 있는 행 전체 삭제
df.dropna(subset=['이름'])   # 특정 열 기준으로만

# 대체
df['나이'] = df['나이'].fillna(df['나이'].mean())   # 평균으로
df.ffill()               # 이전 값으로 채움 (forward fill)
df.bfill()               # 이후 값으로 채움 (backward fill)
```

> **정수 열에 NaN이 섞이면 자동으로 `float64`로 바뀐다.** Pandas의 기본 정수 타입은 NaN을 표현하지 못하기 때문이다. `25`가 `25.0`으로 보이는 이유가 이것이다.

___

## 📌 중복 제거

```python
df.duplicated().sum()               # 중복 행 개수
df.drop_duplicates()                # 중복 제거 (첫 행 유지)
df.drop_duplicates(subset=['이름'])  # 특정 열 기준
```

`keep` 옵션으로 어느 행을 남길지 정한다.

| 값 | 설명 |
| --- | --- |
| `'first'` (기본) | 첫 번째 행 유지 |
| `'last'` | 마지막 행 유지 |
| `False` | 중복된 행을 **모두 제거** |

___

## 📌 피벗 (Pivot)

행과 열을 재배치해 표를 재구성한다. `index`(행), `columns`(열), `values`(값)로 어떤 열을 어디에 배치할지 지정한다.

```python
df.pivot(index='날짜', columns='제품', values='판매량')
# 제품            A    B
# 날짜
# 2024-01-01  100  200
# 2024-01-02  150  250
```

`pivot`과 `pivot_table`의 차이를 알아야 한다.

| | `pivot()` | `pivot_table()` |
| --- | --- | --- |
| 중복 키 | **불가 (오류)** | 가능 (집계) |
| 집계 함수 | 없음 | `aggfunc` 지정 |
| 결측치 | 없음 | `fill_value`로 처리 |

```python
df.pivot_table(index='날짜', columns='제품', values='판매량',
               aggfunc='sum', fill_value=0)
```

> 같은 `index`·`columns` 조합에 값이 **여러 개면 `pivot`은 에러**가 난다. 이때는 집계 함수로 값을 합칠 수 있는 `pivot_table`을 쓴다. 실무에서는 `pivot_table`을 더 많이 쓴다.

___

## 📌 문자열 처리

Series의 **`.str` 접근자**로 문자열을 처리한다. 반복문 없이 배열 전체에 문자열 메서드를 적용하는 **벡터화** 방식이다.

```python
s.str.upper() / s.str.lower()      # 대소문자
s.str.strip()                      # 앞뒤 공백 제거
s.str.replace('시', '')            # 치환
s.str.contains('김')               # 패턴 포함 여부 (필터링에 활용)
s.str.len()                        # 길이
```

분리와 정규표현식 추출도 자주 쓴다.

```python
# 구분자로 분리 후 여러 열로 확장
df_split = s.str.split('-', expand=True)

# 정규표현식으로 추출 — '홍길동(25세)' → 25
s.str.extract(r'\((\d+)세\)')
```

> `.str` 메서드는 요소별로 적용되며, **값이 NaN인 곳은 결과도 NaN**으로 남는다. `expand=True`를 주면 분리 결과가 리스트가 아니라 **여러 열의 DataFrame**으로 펼쳐진다.
