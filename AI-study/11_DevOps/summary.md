# DevOps 한줄 정리

## 운영 모델

| 개념 | 한줄 정리 |
|------|------|
| DevOps | 개발(Dev)과 운영(Ops)의 경계를 허물어 빌드·배포·운영을 자동화하고 협업하는 방법론 |
| DevSecOps | DevOps 파이프라인 초기 단계부터 보안(Sec) 검증을 통합해 자동으로 수행하는 방식 |
| GitOps | Git 저장소를 인프라·배포 상태의 단일 진실 공급원(SSOT)으로 삼아 선언적으로 운영하는 방식 |

## 인프라 기초 (AWS)

| 개념 | 한줄 정리 |
|------|------|
| AWS EC2 | 필요한 만큼 가상 서버(인스턴스)를 빌려 쓰는 AWS의 컴퓨팅 서비스 |
| AWS Security Group | EC2 인스턴스의 인바운드·아웃바운드 트래픽을 포트·IP 단위로 제어하는 가상 방화벽 |

## 전통적 배포

| 개념 | 한줄 정리 |
|------|------|
| 빅뱅 배포 | 기존 버전을 한 번에 전부 새 버전으로 교체하는 방식, 단순하지만 배포 중 서비스 중단과 롤백 부담이 큼 |

## 컨테이너 기초

| 개념 | 한줄 정리 |
|------|------|
| Docker | 애플리케이션과 실행 환경을 컨테이너로 묶어 어디서나 동일하게 실행되게 하는 컨테이너 플랫폼 |
| Dockerfile | 이미지를 어떤 순서로 빌드할지 명령어로 기술한 설계도 파일 |
| Image | 실행에 필요한 코드·라이브러리·설정을 담은 읽기 전용 템플릿 |
| Container | 이미지를 실행해 만들어진 격리된 프로세스 인스턴스 |
| Registry | 이미지를 저장·배포·공유하는 저장소 (Docker Hub, AWS ECR 등) |

> **Image ↔ Container**: 이미지는 **설계도(정적)**, 컨테이너는 그 이미지를 **실행한 상태(동적)** — 이미지 하나로 컨테이너 여러 개 생성 가능

## 컨테이너 관리·네트워크·프록시

| 개념 | 한줄 정리 |
|------|------|
| Portainer | 컨테이너·이미지·볼륨·네트워크를 웹 UI로 관리하는 도커 관리 도구 |
| Volume | 컨테이너가 삭제돼도 데이터가 남도록 호스트에 분리 저장하는 영속 저장소 |
| Bridge Network | 같은 호스트의 컨테이너끼리 컨테이너 이름으로 통신하게 해주는 기본 가상 네트워크 |
| Reverse Proxy | 클라이언트 요청을 먼저 받아 뒤쪽 서버로 전달·분배하는 중개 서버 (Nginx 등) |
| Docker Compose | 여러 컨테이너의 구성을 YAML 한 파일에 선언해 한 번에 실행·관리하는 도구 |

## CI/CD 도구

| 개념 | 한줄 정리 |
|------|------|
| Continuous Integration (CI) | 코드 변경을 자주 통합하며 빌드·테스트를 자동 실행해 문제를 조기에 발견하는 방식 |
| Continuous Deployment (CD) | 검증을 통과한 빌드를 운영 환경까지 자동으로 배포하는 방식 |
| GitHub Actions | GitHub 저장소의 이벤트(push·PR 등)를 트리거로 워크플로를 실행하는 내장 CI/CD 서비스 |
| Jenkins | 플러그인 기반으로 파이프라인을 자유롭게 구성하는 오픈소스 자동화 서버 |

## 무중단 배포 전략

| 개념 | 한줄 정리 |
|------|------|
| Zero-downtime Deployment | 서비스 중단 없이 구버전에서 신버전으로 전환하는 배포 방식 |
| Blue/Green Deployment | 동일 환경 두 벌(운영 Blue·신규 Green)을 두고 트래픽을 한 번에 전환, 롤백이 빠르지만 자원 2배 필요 |
| Rolling Deployment | 인스턴스를 조금씩 순차 교체, 추가 자원은 적게 들지만 배포 중 두 버전이 공존 |
| Canary Deployment | 소수 트래픽에만 신버전을 먼저 노출해 이상 없으면 점진적으로 비중 확대 |

> **3전략 비교**: **Blue/Green**=한 번에 전환(빠른 롤백, 자원↑) / **Rolling**=순차 교체(자원↓, 버전 혼재) / **Canary**=점진 노출(위험 최소, 관리 복잡)
